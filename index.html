Privacy Policy and Support

This privacy policy explains the type, scope, and purpose of the processing of personal data within my app "Aurum - Budget & Expenses".

1. Support

Do you need help or have general questions about the app? You can email me at any time:

Email: moc.duolci@pohs_uh.uj

2. Technical Support & Diagnostics

When using the "Support" feature, a technical support file is generated, which the user sends voluntarily. This file is used exclusively for error analysis and contains only technical diagnostic information (e.g., App/OS version, device class, language/region, time zone, technical status/timestamps, function counters, technical UI flow logs).

The file contains no financial content (no amounts, no expense descriptions/notes, no category/label names, no export/import data). Generation and transmission occur only upon active user action; no transmission takes place without the user sending the file. The recipient is the specified support address; the file is processed solely for handling the support case and is deleted as soon as it is no longer required.

3. Data Storage

All budget data entered by you is saved exclusively locally on your device or in your personal iCloud storage. I do not have access to your financial data at any time.

4. Analytics (TestFlight)

During the beta phase via TestFlight, crash reports and usage information are transmitted to Apple and me to improve the app. This is a standard feature of Apple TestFlight.
